# Snake AI - Neural Network with Genetic Algorithm

An AI-powered Snake game that learns to play using Neural Networks trained with a Genetic Algorithm.

## About This Project

This is my university dissertation project. It demonstrates:
- Neural Networks (15 input neurons, 10 hidden, 4 output)
- Genetic Algorithm (selection, crossover, mutation)
- 100 AI agents learning simultaneously
- Real-time visualization of evolution

## How to Run

Just open `index.html` in any web browser and click "Start Evolution" to watch the AI learn!

## Technologies

- JavaScript
- HTML5 Canvas
- Neural Networks (built from scratch)
- Genetic Algorithms

## What the AI Learns

The snakes start with random behaviors and improve over generations by:
1. Keeping the best performers
2. Combining their "brains" (neural networks)
3. Adding random mutations
4. Repeating for many generations

Watch as they get progressively better at avoiding walls and finding food!
